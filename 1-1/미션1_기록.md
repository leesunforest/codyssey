# 미션 1 기록

- AI B 이름 / 대화 공유 링크 또는 캡처 파일명: ChatGPT (GPT 5.6 Terra) / gpt.png
- AI가 물어서 내가 정한 것:
  - 누가 쓰나: 나 혼자 씀. 친구들에게는 보여주기만 함
  - 목적: 내 영화 취향 정리
  - 여는 곳: 처음엔 노트북과 폰 둘 다라고 답함 → PC 브라우저에서만으로 바꿈
  - 등급: S / A / B / C 4개
  - 옮기는 방법: 끌어다 놓기만. 폰에서는 끌어다 놓기가 잘 안 된다는 말을 듣고 "누르고 등급 누르기"를 넣었다가, PC로만 바꾸면서 다시 뺌
  - 다시 열었을 때: 배치한 그대로 남음
  - 영화 목록: 8편으로 시작하고 추가와 삭제 둘 다 가능
  - 삭제 방법: 카드를 누르면 [삭제] 버튼이 나옴
  - 처음 상태로 돌리는 버튼: 넣지 않음
  - 빼는 기능: 로그인·회원가입, 온라인 공유, 포스터 이미지
  - 새로 추가한 영화: 미분류 칸에 들어감
  - 빈칸이나 띄어쓰기만 넣었을 때: 카드가 안 생기고 "제목을 입력해 주세요" 안내
  - 같은 제목을 또 넣었을 때: 막고 "이미 있는 영화예요" 안내
  - 완성 기준: AI가 제시한 후보 8개를 전부 선택. PC로 바꾸면서 폰 관련 기준 1개는 뺌
- 같은 행동으로 비교한 결과(해본 행동 → 기대 결과 → A의 결과 / B의 결과):
  * HTML 파일을 브라우저에서 열기 → 바로 실행됨 → A: 실행됨 / B: 실행됨
  * 영화 카드를 S 등급 칸으로 끌어 놓기 → 해당 카드가 S 칸으로 이동하고 한 칸에만 존재함 → A: 동작함 / B: 동작함
  * 카드 클릭 → 삭제 버튼 표시 → A: 동작함 / B: 동작함
  * 제목 없이 추가 → "제목을 입력해 주세요" 안내 → A: 동작함 / B: 동작함
  * 기존 제목인 "기생충" 추가 → "이미 있는 영화예요" 안내 → A: 동작함 / B: 동작함
  * 브라우저를 다시 열기 → 영화 배치·추가·삭제 결과 유지 → A: localStorage로 저장됨 / B: localStorage로 저장됨
  * 브라우저 폭을 좁히기 → 화면 오른쪽이 잘리지 않음 → A: 기본 반응형 구성 / B: 좁은 폭에서 입력 영역과 티어 칸이 재배치되어 잘리지 않음
- 선택한 파일명과 고른 이유: 영화_B_초안.html. 같은 행동 7가지를 두 파일에 해 본 결과 A와 B 모두 기획서의 완성 기준대로 동작해서 기능 차이는 없었음. 그래서 화면을 기준으로 골랐고, B의 다크모드와 디자인이 더 마음에 들어서 B를 선택함.
