# 민수 님께 드리는 피드백

> 초안입니다. `✍️` 표시는 직접 해 본 내용으로 채우거나 고칠 곳입니다.

잘된 점: ✍️ [직접 써 보니 좋았던 것. 예: 카드를 누르고 등급 글자를 누르는 방법과 끌어 놓는 방법이 둘 다 돼서 편했어요]

고치면 좋을 점
1. 본 것: 영화를 옮기고 새 영화를 추가한 뒤 새로고침했더니, 옮긴 배치와 추가한 영화가 모두 사라졌다
   기준: 기획서의 "같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다"
   제안: 옮기거나 추가할 때마다 브라우저에 저장하고, 다시 열 때 불러오면 좋겠어요

2. 본 것: 브라우저 창 폭을 ✍️ [얼마나] 줄였더니 오른쪽이 잘려서 ✍️ [안 보인 것. 예: '처음으로' 버튼, 편수 표시]이 보이지 않았다
   기준: 기획서의 "화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다"
   제안: 창이 좁아지면 내용 폭도 같이 줄고, 넘치는 줄은 아래로 내려가면 좋겠어요

3. 본 것: 제목을 입력하고 Enter를 눌렀더니 카드가 추가되지 않았다 ✍️ [조건. 예: 한글 제목일 때 Enter 한 번]
   기준: 기획서에는 없지만(기획서는 "'추가'를 누르면"), 쓰다가 불편했던 점
   제안: 한글을 입력한 뒤 Enter를 한 번만 눌러도 추가되면 좋겠어요
