# 민수 님께 드리는 피드백

잘된 점: 카드를 누르고 등급 글자를 누르는 방법과 끌어 놓는 방법이 둘 다 잘 됩니다. 등급마다 색이 달라 칸이 한눈에 구분되고, 옮길 때마다 "8편 중 n편 나눔"이 바뀌어서 남은 수를 알기 쉬웠습니다. '처음으로'를 누르면 추가한 영화까지 지우고 처음 8편을 모두 미분류로 되돌립니다.

고치면 좋을 점

1번과 2번은 기획서의 완성 기준을 지키지 못한 부분이라 먼저 고치시고, 3번과 4번은 쓰기 편하게 다듬는 부분이라 그다음에 고치시면 좋겠습니다.

1. 본 것: 영화를 옮기고 새 영화를 추가한 뒤 새로고침했더니, 옮긴 배치와 추가한 영화가 모두 사라졌다
   기준: 기획서의 "같은 브라우저에서 같은 파일을 다시 열어도 영화와 등급이 남습니다"
   제안: 옮기거나 추가할 때마다 브라우저에 저장하고, 다시 열 때 불러오면 좋겠습니다

2. 본 것: 브라우저 창 폭을 720px로 줄였더니 오른쪽이 잘려서 '처음으로' 버튼과 "8편 중 n편" 표시가 보이지 않았고, 옆으로 스크롤도 되지 않았다
   기준: 기획서의 "화면 폭이 좁아져도 오른쪽이 잘리지 않고 내용을 볼 수 있습니다"
   제안: 창이 좁아지면 내용 폭도 같이 줄고, 넘치는 부분은 아래로 내려가면 좋겠습니다

3. 본 것: 빈칸이나 띄어쓰기만 넣고 '추가'를 눌렀더니 글자 없는 카드가 생겼다
   기준: 기획서에는 없지만, 빈 카드는 지울 방법이 없어 쓰다가 불편했던 점
   제안: 빈 제목이면 카드를 만들지 않고 "제목을 입력해 주세요"라고 알려 주면 좋겠습니다

4. 본 것: 한글 제목을 입력하고 Enter를 눌렀더니 추가되지 않았다('추가' 버튼을 누르면 추가됨)
   기준: 기획서에는 없지만(기획서는 "'추가'를 누르면"), 쓰다가 불편했던 점
   제안: 한글을 입력한 뒤 Enter를 한 번만 눌러도 추가되면 좋겠습니다
