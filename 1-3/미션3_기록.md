# 미션 3 기록

- 확인 방법: 자동 브라우저(Playwright, Chromium)로 민수_영화티어리스트.html을 열어 2회 반복. 결과는 `검증/직접써보기_결과.txt`, 캡처는 `검증/*.png`
- 순서: 받은_피드백.md를 열기 전에 완성 기준부터 직접 해 봄 → 그다음 피드백을 하나씩 다시 해 봄

| 받은 의견 | 직접 해 본 결과 | 반영 / 보류 / 되묻기 | 이유 (되묻기라면 물을 질문) |
|---|---|---|---|
| AI 1. 저장 기능이 없어 다시 열면 미분류로 돌아감 | 8편을 나누고 '어바웃 타임'을 추가한 뒤 새로고침 → 12장이 처음 8장으로 돌아가고 모두 미분류. 브라우저 저장 항목 0개 | 반영 | 완성 기준 "다시 열어도 영화와 등급이 남습니다"를 어김 |
| AI 2. '처음으로'가 추가한 영화를 지우지 않음 | '괴물'을 추가하고 '처음으로' → 처음 8편만 남고 '괴물'은 사라짐. 8편 모두 미분류 | 보류 | 직접 해 보니 틀린 지적. '처음으로'는 기획서대로 동작함 |
| AI 3. 빈 제목을 막지 않아 기획서를 어김 | 빈칸, 띄어쓰기만 넣고 추가 → 글자 없는 카드가 생기고 "‘’를 추가했어요" 안내 | 반영 | 현상은 맞음. 다만 기획서에 "빈 제목을 막는다"는 조건은 없어서 "기획서를 어김"은 지나친 표현. 쓰기 불편해서 반영 |
| AI. "세 가지 외에는 완성 기준을 잘 지킴" | 960px보다 좁으면 오른쪽이 잘리고 스크롤도 안 됨(완성 기준 위반). 같은 제목 추가도 막지 않음 | 보류 | 틀림. 놓친 문제가 있음(아래) |
| 동료 +. 등급마다 색이 달라 한눈에 보임 | S 빨강, A 주황, B 초록, C 파랑으로 구분됨 | 반영 | 맞음. 잘된 점으로 전함 |
| 동료 +. '8편 중 3편 나눔'으로 남은 수가 보임 | 옮길 때마다 "8편 중 n편 나눔"이 바뀜 | 반영 | 맞음. 잘된 점으로 전함 |
| 동료 +. 끌 때 칸 색이 바뀜 | C칸 위로 끌면 흰색 → 연한 베이지로 바뀜. 차이가 작아 잘 안 보임 | 반영 | 맞음. 잘된 점으로 전함 |
| 동료 -. 휴대폰으로 열어 보니 불편 | 480px에서 오른쪽 480px이 잘리고 '처음으로' 버튼이 안 보임 | 되묻기 | "무엇을 하려다 어떻게 불편했나요? 오른쪽이 잘린 건가요, 끌어 놓기가 안 된 건가요?" |
| 동료 -. 처음엔 옮기는 게 헷갈림 | 안내 문구("카드를 선택한 뒤 등급을 누르세요")가 있고, 누르기·끌기 둘 다 동작함 | 되묻기 | "어떤 걸 해 봤는데 어떻게 됐나요?" |
| 동료 -. 미분류가 맨 아래라 S칸까지 끌기 불편 | 1440×900 창에서 S칸은 313px, 첫 카드는 1058px에 있어 한 화면에 안 보임 | 보류 | 현상은 맞음. 하지만 기획서가 "아래에 안 정한 영화"로 정했고, 누르고 등급 글자를 누르는 방법으로는 스크롤 없이 옮길 수 있음 |
| 동료 -. 카드 색이 칙칙함 | 회색 카드 | 보류 | 취향 |
| 동료 -. 포스터가 있으면 좋겠음 | 포스터 없음 | 보류 | 기획서 조건 "외부 파일 없이 HTML 한 장"과 부딪힘 |
| 동료 -. C칸은 없어도 됨 | - | 보류 | 기획서 목적이 S·A·B·C로 나누기임 |
| 동료. 큰 문제 없어 PASS | 저장 안 됨, 좁은 화면에서 잘림 | 보류 | 완성 기준 두 개를 지키지 못함 |

- 아무도 말하지 않았는데 내가 찾은 것:
  - 창 폭이 960px보다 좁으면 내용이 오른쪽으로 잘리고, 가로 스크롤도 안 됨. 720px에서는 '처음으로' 버튼과 "8편 중 n편" 표시가 화면 밖으로 나감 (완성 기준 "화면 폭이 좁아져도 오른쪽이 잘리지 않음" 위반)
  - 같은 제목을 다시 추가할 수 있음. '인터스텔라'를 추가하면 A칸과 미분류에 같은 영화가 둘 생김 (완성 기준 "영화가 한 칸에만 있음"과 어긋남)
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: AI가 '처음으로'를 틀리게 지적한 것. 그럴듯한 설명이라도 직접 해 보지 않으면 잘못 반영할 수 있어서
