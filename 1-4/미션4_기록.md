# 미션 4 기록

- 사용한 AI 이름 / 주요 대화 캡처 파일명: Claude (Claude Code, 모델 이름은 캡처 오른쪽 아래에 표시) / `대화내용캡쳐.png`
- 더한 기능과 고른 이유: 칸별 영화 개수. S·A·B·C 칸과 '아직 안 정한 영화'에 몇 편이 있는지 바로 보여서, 얼마나 나눴고 얼마나 남았는지 알 수 있어서 골랐습니다.

| 받은 파일 | 맞지 않은 완성 기준 | 한 일 (고치기 / 원래 파일로 돌아가기 / 완성) |
|---|---|---|
| 영화_기능추가.html | 없음 | 완성 |

- 완성본: `영화_기능추가.html`
- 확인한 것 (영화_기능추가.html, 기획서.md 완성 기준 순서대로):
  - 카드를 누르고 등급 글자를 눌러 옮기기, 끌어 놓아 옮기기 → 둘 다 되고 영화는 한 칸에만 남음. 개수가 들어간 S·A·B·C 글자를 눌러도 옮겨짐
  - 새 제목 추가 → 미분류에 카드가 생김
  - 빈 제목 추가 → 추가되지 않음
  - 새로고침 → 영화와 등급, 개수가 그대로 남음
  - 창 폭을 좁힘 → 오른쪽이 잘리지 않음
  - '처음으로' → 처음 영화 8개가 모두 미분류로 돌아가고 개수도 S·A·B·C 0편, 미분류 8편으로 돌아옴
  - HTML 한 장으로 바로 열림
  - 새 기능: 옮기기, 추가, '처음으로'를 할 때마다 칸별 개수가 바로 맞게 바뀜
- 고치기(4단계)와 원래 파일로 돌아가기(5단계)는 하지 않았습니다. 첫 파일에서 새 기능과 원래 기능이 모두 완성 기준대로 동작해, 고칠 것도 망가진 것도 없었기 때문입니다. 그래서 `영화_기능추가_수정1.html`은 없습니다.
- 원본 `영화_원본.html`은 `[미션4]샘플과 코랩세션질문지/샘플/`에 고치지 않고 그대로 두었습니다.
- (선택) 코랩에서 함께 이야기하고 싶은 내용과 그 이유: 원래 기능이 망가지지 않게 요청하는 방법. "원래 기능은 바꾸지 마"라고 적었더니 바뀐 곳이 두 줄뿐이었는데, 다른 사람은 어떻게 요청했는지 비교해 보고 싶어서
