# 내 영화 티어리스트

## 사용
- 나 혼자 쓰고, 친구에게는 결과만 보여 줌
- PC 브라우저 전용
- 목적: 내 영화 취향 정리

## 화면과 동작
- S·A·B·C 등급 칸과 미분류 칸
- 카드는 끌어다 놓기로만 옮김
- 카드를 누르면 [삭제] 버튼 표시
- 제목 입력 후 [추가] → 미분류 칸에 새 카드
  - 빈칸: "제목을 입력해 주세요"
  - 중복: "이미 있는 영화예요"
- 창을 닫았다 열어도 배치 유지
- 부제는 늘 한 줄. 자리가 모자라면 제목 아래로 이동
- 넣지 않음: 초기화 버튼, 로그인, 온라인 공유, 포스터

## 처음 영화
기생충, 인터스텔라, 라라랜드, 센과 치히로의 행방불명, 어벤져스: 엔드게임, 범죄도시, 타이타닉, 토이 스토리

## 완성 기준
- 영화 하나는 한 칸에만 있음
- 끌어서 S칸에 놓으면 S칸으로 이동
- [삭제]를 누르면 카드가 사라짐
- [추가]를 누르면 새 카드가 생김
- 다시 열어도 배치·추가·삭제 결과 유지
- 창 폭을 절반으로 줄여도 오른쪽이 잘리지 않음
- 창 폭이 바뀌어도 부제가 한 줄이고, 글자 크기가 갑자기 바뀌지 않음
- 서버 없이 HTML 파일 하나로 열림
