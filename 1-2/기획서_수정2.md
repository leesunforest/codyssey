# 🎬 Movie Archive (수정2 기획)

`기획서.md`에서 바뀐 점만 적습니다.

## 화면
- 넷플릭스 홈 화면형. 배경은 검정, 글자는 흰색, 글꼴은 Pretendard
- 배너: S등급 첫 영화. 제목, 등급 배지, 연도·평점, [상세 정보] 버튼
- 등급(S·A·B·C·D·미분류) 하나가 포스터 한 줄. 가로 스크롤, 양끝 화살표
- 헤더에 홈·S·A·B·C·D·미분류 메뉴. 누르면 그 줄로 이동
- 포스터는 2:3 비율. 마우스를 올리면 살짝 커짐
- 상세 팝업: 대표 이미지, 제목·평점·연도, 유튜브 예고편 링크, 줄거리(단어 단위 줄바꿈), 오른쪽 아래 흰색 [삭제] 버튼

## 동작
- 처음 영화 없이 빈 등급표로 시작
- 돋보기로 검색(TMDB) → 결과 팝업에서 [추가] → 미분류 줄로 들어감
- 등급은 포스터를 다른 줄로 끌어다 놓아 바꿈
- 닉네임 + 숫자 4자리 비밀번호로 접속. 닉네임마다 따로 저장(이 브라우저에만)
- TMDB 키는 `config.js`에 넣음(GitHub에 올리지 않음)

## 완성 기준
- 내 닉네임으로 들어가면 내 등급표만 보임
- 검색해서 추가하면 포스터 카드가 미분류 줄에 생김
- 다시 열고 같은 닉네임으로 들어가도 배치가 그대로임
