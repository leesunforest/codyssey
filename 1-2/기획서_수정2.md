# 내 영화 티어리스트 (수정2 기획)

`기획서.md`를 바탕으로 아래 내용을 바꾼 새 기획입니다. 적지 않은 내용은 `기획서.md`를 따릅니다.

## 바뀐 점

- 디자인: 구글 Material Design 3 규칙(색 역할, 글자 역할, 둥근 모서리, 버튼·입력칸 모양)을 따릅니다.
- 글꼴: Pretendard를 씁니다. 인터넷이 없으면 기기 기본 한글 글꼴로 보입니다.
- 배경: 블랙 단일 색입니다.
- 처음 영화 8편은 넣지 않습니다. 빈 등급표에서 시작합니다.
- 영화 추가: 제목을 검색하면 TMDB(The Movie Database) API 결과가 포스터·한국어 제목·개봉 연도·원제와 함께 나오고, [추가]를 누르면 포스터와 제목이 미분류 칸에 들어갑니다.
  - 빈칸으로 검색하면 "제목을 입력해 주세요" 안내가 나옵니다.
  - 이미 넣은 영화는 [추가됨]으로 바뀌고 다시 넣을 수 없습니다.
  - 포스터가 없는 영화는 "포스터 없음"으로 보입니다.
  - 서비스 키는 같은 폴더의 `config.js`에 넣습니다(`config.example.js`를 복사해 만듦). 이 파일은 GitHub에 올리지 않고, 키가 있으면 화면에 [API 키] 버튼이 보이지 않습니다.
- 접속: 닉네임과 숫자 4자리 비밀번호로 들어갑니다.
  - 처음 쓰는 닉네임이면 새로 만들어지고, 있는 닉네임에 다른 비밀번호를 넣으면 "비밀번호가 맞지 않아요" 안내가 나옵니다.
  - 닉네임마다 자기 등급표가 따로 저장됩니다.
  - 저장은 지금 쓰는 브라우저 안에만 됩니다. 다른 컴퓨터나 다른 브라우저에서는 보이지 않습니다.

## 완성 기준 (추가)

- 닉네임과 비밀번호로 들어가면 그 사람의 등급표만 보인다.
- 영화를 검색해 [추가]를 누르면 포스터와 제목이 있는 카드가 미분류 칸에 생긴다.
- 창을 닫았다 열고 같은 닉네임·비밀번호로 들어가면 배치가 그대로 남아 있다.
